# 项目理解与搜索

DeepCCC CLI、Web 与 ChatCCC 内置 CCC 共用这些能力。无需配置向量服务、下载模型或修改项目指令文件；地图与证据保存在本机 `~/.deepccc/workspace-index/<工作目录哈希>/`。不在不同工作目录间自动合并知识（包括 worktree）。选入上下文的片段仍会随正常模型请求发送给用户配置的模型服务；“本地索引”不意味着模型请求离线。

## 搜索范围不是权限边界

- `search_code({query: "Policy"})`：默认 `project`，跳过常见依赖/构建目录及隐藏条目；ripgrep 还遵循 ignore 文件。
- `search_code({query: "Policy", scope: "all"})`：包含依赖、隐藏及被忽略文件。不自动跟随目录符号链接，也不提升操作系统权限。
- `search_code({query: "forward", path: ".venv/Lib/site-packages/example"})`：指定非工作目录根的路径时，缺省按 `all` 搜索。调用者可显式选择 `project`。
- `scope`、`excluded`、`engine`、`warnings`、`truncated` 描述实际查询边界。无命中不证明项目中不存在相关能力。
- Node 降级搜索支持相同的 project/all 范围切换，但不解析 `.gitignore`/`.ignore`，会明确返回警告；正则为 JavaScript 语法。正常路径优先使用内置 ripgrep，不拼接 shell 命令。

明确指定文件时保留文件名输出，避免单文件命中被解析器丢弃。无效正则、超时、取消等不会伪装成正常无命中；降级路径跳过不可读条目时返回警告。

## 有限预算的项目地图

`workspace_map({query: "Policy", path: "可选目录", maxChars: 6000})` 提供文件清单、部分定义/导入/文档标题线索和证据笔记。支持 TS/JS、Python、Go、Rust、Java、C#、C/C++、Ruby、PHP 等文本线索；其他文件仍可按名称发现并用读取/搜索工具检查。

这是**词法导航，不是 AST、完整调用图或语义向量索引**。定义优先于导入，查询相关片段优先展示。默认不遍历隐藏、虚拟环境或构建目录；可指定其目录生成地图。地图不解析 Git ignore 规则，这一点在输出中明确提示。JSON/TOML 配置值不作为符号片段展示；package.json 只提取有限的入口和脚本名称。

每次刷新重新枚举并检查内容哈希，复用未变化文件的提取结果；能识别同长度修改、删除、新增及切换分支后的变化。默认上限为 1500 个目录/文件条目、约 2 秒扫描检查预算、8 MiB 已读源码，单文件 128 KiB。预算不是磁盘 I/O 的强制超时；网络挂载或慢盘可能超过此时间。超预算用 `partial` 表示；展示省略用 `displayTruncated` 表示。大仓库需要查询相关子目录，不能从部分地图得出全局否定结论。

项目相关问题或“继续”类消息会自动获得最多 3000 字符的导航；其他任务随时可调用工具。识别属于轻量启发式，不保证覆盖所有问法。自动导航不进入持久化历史，避免每轮累加；缓存损坏或不可写时继续使用实时读取/搜索，不阻断对话。

## 带来源的长期笔记

`remember_project_fact({fact, path, excerpt})` 保存简短的项目能力/关系解释，以及当前文件中确实匹配的原文、SHA-256 和记录时间。证据文件必须位于当前工作目录内（解析符号链接后校验）。不可读、超大文件或不匹配原文会拒绝保存。

笔记只存在用户缓存目录，独立于聊天摘要，因此可在压缩或重开会话后通过地图检索。同工作目录的会话共享笔记。展示前重新校验源文件；修改、删除或移动后旧笔记不再注入，但磁盘记录保留以便诊断。最多检查最近 20 条笔记，展示还受预算限制。请勿保存密钥、授权令牌、用户指令或未经证实的断言。

原文匹配**只验证来源，不证明模型解释正确**；输出明确标注“agent interpretation”。针对同一文件和同一原文重新保存解释，会替换此前笔记。即使文件未变，相关配置/调用方也可能变化，重要决策仍需重新查证。压缩器会区分任务进度、已核实项目事实与推测，并优先保留纠正和源码入口。

## 测试边界

自动化测试覆盖依赖目录显式访问、搜索失败/无命中/截断、单文件输出解析、地图更新、证据失效、预算与取消，以及导航不会在历史中累积。这些是工具和上下文护栏，不是所有模型都能正确理解项目的保证；未对某个在线模型宣称准确率提升。

## 长会话状态与轮内预算

压缩器每次重写完整摘要，使用固定章节区分当前事实、仍待处理、已取代历史、项目事实、证据/推断/局限和重要操作。最近原始消息、明确纠正及当前磁盘事实优先；旧摘要中的助手评价不是事实或用户指令。旧格式摘要仍可读取，但在模型输入中会明确标记为历史材料，避免把已完成或回退的路线恢复成当前建议。

同一轮 Agent 可能连续执行多个工具，AI SDK 会把先前结果重复发送到后续模型步骤。DeepCCC 在每一步前对这些结果执行结构保持的预算控制：每项最多约 24,000 字符，总量约 96,000 字符，最近 4 项优先。较早结果必要时替换为可识别的省略标记，assistant tool-call 与对应 `role: tool` 结果仍成对保留。该处理只影响本轮后续模型请求；用户界面事件、最终持久化记录和受独立上限保护的 raw stream log 不被这一步改写。需要细节时 Agent 应重新执行更聚焦的读取或搜索。
